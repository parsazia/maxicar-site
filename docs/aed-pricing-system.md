# سیستم قیمت‌گذاری ماکسیکار بر پایه درهم

وضعیت: مشخصات مورد توافق برای پیاده‌سازی در محیط آزمایشی؛ هنوز هیچ قیمت محصولی تغییر داده نمی‌شود.

## هدف
مدیر فروشگاه قیمت پایه هر محصول را به درهم وارد می‌کند. سیستم نرخ روز درهم را از TGJU می‌خواند، قیمت فروش را به تومان محاسبه می‌کند، به گام ۲۵٬۰۰۰ تومان رو به بالا گرد می‌کند و پس از تأیید مدیر، قیمت محصول را از طریق API میکسین/میکسن به‌روزرسانی می‌کند. اجرای قیمت‌گذاری دستی و هنگام نیاز است، نه زمان‌بندی روزانه.

## قواعد محاسبه
1. نرخ درهم از منبع TGJU خوانده می‌شود. اگر نرخ به ریال نمایش داده شده باشد، برای تبدیل به تومان بر ۱۰ تقسیم می‌شود.
2. قیمت پایه هر محصول مستقل از قیمت فعلی تومان نگهداری می‌شود؛ تغییر قیمت تومان نباید قیمت پایه درهم را بازنویسی کند.
3. فرمول:
   `قیمت خام تومان = قیمت پایه درهم × نرخ درهم به تومان`
   `قیمت فروش = ceil(قیمت خام تومان / 25000) × 25000`
4. نمونه: قیمت خام ۲٬۷۳۰٬۰۰۰ تومان به ۲٬۷۵۰٬۰۰۰ تومان گرد می‌شود.
5. محاسبات با اعداد صحیح و کنترل اعتبار ورودی انجام می‌شود تا خطای اعشاری و قیمت منفی/صفر وارد نشود.

## نگهداری داده
- قیمت پایه درهم باید در فیلد اختصاصی محصول در `extra_fields` ذخیره شود؛ نام کلید دقیق باید با ساختار واقعی API و فیلدهای قابل‌ویرایش فروشگاه تطبیق داده شود.
- قیمت نهایی فروش در فیلد معمول قیمت محصول (`price`) ثبت می‌شود.
- هر اجرای قیمت‌گذاری باید گزارشی شامل شناسه و نام محصول، قیمت پایه درهم، نرخ استفاده‌شده، زمان دریافت نرخ، قیمت قبلی، قیمت محاسبه‌شده و نتیجه عملیات داشته باشد.
- توکن API فقط از تنظیمات محرمانه محیط سرور خوانده می‌شود؛ هرگز در مرورگر، کد عمومی، گزارش‌ها یا رابط کاربری نمایش داده نمی‌شود.

## دامنه اعمال
- فقط محصولاتی پردازش می‌شوند که قیمت پایه درهم معتبر دارند و در وضعیت قابل فروش/موجودی قرار دارند.
- محصول بدون قیمت پایه درهم تغییر نمی‌کند.
- محصول ناموجود، خارج از موجودی یا دارای وضعیت نامشخص تغییر نمی‌کند.
- قیمت محصولات با مبنای غیر درهم دست‌نخورده می‌ماند.
- هیچ تغییر گروهی روی قیمت‌ها بدون پیش‌نمایش و تأیید صریح مدیر انجام نمی‌شود.

## نمایش قیمت در سایت
- برای محصول واجد شرایط، قیمت محاسبه‌شده به تومان نمایش داده می‌شود.
- قیمت پایه درهم به‌صورت پیش‌فرض برای مشتری نمایش داده نمی‌شود.
- محصولی که قیمت پایه درهم ندارد، قیمت دستی فعلی خود را حفظ می‌کند؛ اگر قیمت معتبری ندارد، وضعیت «استعلام قیمت» نمایش داده می‌شود.
- محصول ناموجود با وضعیت موجودی واقعی نمایش داده می‌شود و قیمت آن به‌صورت خودکار بازنویسی نمی‌شود.
- نرخ نامعتبر یا در دسترس نبودن TGJU نباید باعث صفر شدن قیمت یا تغییر قیمت‌ها شود. عملیات باید متوقف شود و خطا به مدیر اعلام شود.
- زمان آخرین محاسبه و منبع نرخ در گزارش مدیریتی ثبت می‌شود؛ نمایش آن به مشتری اختیاری است و نباید به‌عنوان تضمین موجودی تلقی شود.

## جریان اجرایی
1. مدیر قیمت پایه درهم یک یا چند محصول را وارد/اصلاح می‌کند.
2. مدیر دستور «محاسبه قیمت‌ها» را اجرا می‌کند.
3. سرور نرخ روز TGJU را دریافت و اعتبارسنجی می‌کند.
4. سیستم پیش‌نمایش قیمت فعلی و جدید، تغییر مبلغ و درصد تغییر را می‌سازد.
5. مدیر پیش‌نمایش را بررسی و صریحاً تأیید می‌کند.
6. سرور فقط محصولات واجد شرایط را با `PATCH /api/v4/products/{product_id}/` به‌روزرسانی می‌کند.
7. نتیجه هر محصول ثبت می‌شود؛ خطای یک محصول نباید باعث گزارش موفقیت کاذب برای کل عملیات شود.

## الزامات ایمنی و آزمون
- تأیید پاسخ موفق API و سپس بازخوانی محصول برای اطمینان از ثبت قیمت.
- جلوگیری از ارسال دوباره درخواست‌های تکراری ناخواسته.
- ثبت گزارش قابل‌پیگیری برای موفقیت و خطا بدون افشای توکن.
- آزمون نرخ نامعتبر/قدیمی، قطع منبع نرخ، قیمت پایه نامعتبر، محصول ناموجود، محصول بدون قیمت پایه، خطای API، و گردکردن رو به بالا.
- توسعه و آزمون فقط روی شاخه و استقرار آزمایشی؛ دامنه و استقرار فعال `maxicar.ir` نباید تغییر کند.

## مواردی که پیش از اتصال واقعی باید بررسی شوند
- قالب فعلی پاسخ TGJU و انتخاب دقیق نرخ خرید/فروش درهم.
- ساختار واقعی `extra_fields` و نحوه ارسال آن در API میکسین.
- معنای دقیق وضعیت‌های موجودی در API برای تشخیص محصول قابل فروش.
- وجود و سطح دسترسی توکن API در تنظیمات محیط آزمایشی.
- محدودیت نرخ درخواست و پاسخ‌های خطای API.

## معیار پذیرش
- محاسبه با فرمول و گام گردکردن توافق‌شده تطبیق دارد.
- محصولات فاقد قیمت پایه درهم و محصولات ناموجود تغییر نمی‌کنند.
- هیچ قیمتی بدون پیش‌نمایش و تأیید مدیر اعمال نمی‌شود.
- نرخ یا توکن محرمانه در کد سمت مشتری قرار نمی‌گیرد.
- قیمت جدید در API بازخوانی و تأیید می‌شود.
- تمام آزمون‌ها روی نسخه آزمایشی اجرا می‌شوند و سایت فعال دست‌نخورده می‌ماند.
