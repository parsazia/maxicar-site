# زیرساخت اپلیکیشن ماکسیکار

این شاخه زیرساخت اولیهٔ نسخهٔ قابل‌نصب وب را روی پروژهٔ آزمایشی موجود اضافه می‌کند. سایت اصلی و شاخهٔ اصلی تغییر داده نشده‌اند.

## امکانات اضافه‌شده

- فایل manifest برای نصب روی صفحهٔ اصلی گوشی
- ثبت Service Worker برای صفحهٔ جایگزین هنگام قطع اینترنت
- مسیر `GET /api/catalog` به‌عنوان درگاه سروری دریافت فهرست محصولات
- پشتیبانی از حالت نمایشی و حالت متصل به سرویس واقعی
- عدم ذخیره‌سازی پاسخ فهرست محصولات در کش؛ قیمت و موجودی نباید از کش آفلاین نمایش داده شوند

## اتصال به فهرست واقعی محصولات

در تنظیمات محیطی Vercel برای Preview این متغیرها تعریف شوند:

- `MAXICAR_CATALOG_API_URL`: نشانی HTTPS سرویس خواندن محصولات
- `MAXICAR_CATALOG_API_TOKEN`: توکن اختیاری سرویس؛ فقط سمت سرور نگهداری شود

سرویس باید پاسخ JSON به شکل آرایه‌ای از محصولات یا شیئی با کلید `items` یا `products` برگرداند. درگاه، فقط فیلدهای مجاز را به کاربر می‌دهد. تا زمانی که این دو متغیر تنظیم نشده باشند، پاسخ به‌صراحت `mode: "demo"` خواهد بود.

این آداپتور اتصال خودکار به پنل فعلی maxicar.ir ایجاد نمی‌کند. پیش از اتصال، باید API واقعی، احراز هویت، مدل داده، قیمت و وضعیت موجودی از سامانهٔ فعلی تأیید شوند.

## آزمایش

1. اجرای `npm run build`
2. بررسی `/manifest.webmanifest`
3. بررسی `/api/catalog` و اطمینان از `mode: "demo"` پیش از اتصال واقعی
4. پس از تنظیم API در محیط Preview، بررسی `mode: "live"`
5. آزمایش نصب و حالت آفلاین در اندروید و Safari روی iOS

## امنیت و انتشار

- هیچ توکن یا کلید محرمانه‌ای نباید در کد سمت مرورگر یا مخزن ذخیره شود.
- پاسخ‌های API در کش مرورگر یا Service Worker ذخیره نمی‌شوند.
- این تغییرات برای Preview هستند؛ انتشار عمومی نیازمند بررسی و تأیید جداگانه است.
